# Repo Comparison

Compare two GitHub repositories by stars and calculate difference, ratio, and percentage share.

## Parameters

- owner1/repo1
- owner2/repo2

## Steps

1. Get repository details for '{owner1/repo1}' using getRepository
2. Get repository details for '{owner2/repo2}' using getRepository
3. Calculate the star count difference using the calculator subtract tool
4. Calculate the ratio of stars using the calculator divide tool
5. Calculate each repo's percentage share of total stars using add, then divide and multiply
6. Present a comparison summary with star counts, difference, ratio, and percentage shares

## Tools Used

- getRepository
- subtract
- divide
- add
- multiply
