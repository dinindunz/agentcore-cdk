# Memory Viewer

Quick utility to view AgentCore memory records.

## Quick Start

```bash
make view-memory               # View memory for actor from .env
python view_memory.py actor-id # Custom actor ID
```

## What It Shows

- **Preference memory** - User preferences and personalisation
- **Semantic memory** - Facts and knowledge about the user
- **Summary memory** - Session conversation summaries

See **[Manual Testing Guide](../../../docs/MANUAL_TESTING.md#memory)** for complete documentation.
